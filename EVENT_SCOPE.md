## Event-built: capability probe

| Path | Contents | Provenance |
|---|---|---|
| `tools/capability_probe.py` | Minimal probe of the hosted model API: six fixed requests, local validation, sanitized ledger | Written during the event; drafted with an AI coding assistant and run by the repository owner |
| `evidence/event/capability-probe/probe-results.json` | Sanitized record of each probe attempt: request, visible reply, validation result, numeric usage, cost bound | Generated by running the probe during the event |
